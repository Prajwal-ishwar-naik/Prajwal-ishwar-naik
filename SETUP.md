# 🚀 GitHub Profile Setup Guide for Prajwal

Follow these step-by-step instructions to make your GitHub profile look exactly like the creator's with your custom matrix cyber theme, live metrics dashboard, and contribution snake!

## 📌 Step 1: Ensure It's Your Special Profile Repository

On GitHub, a README only appears directly on your main profile page (`https://github.com/Prajwal-ishwar-naik`) if the repository name **matches your GitHub username exactly**.

Your GitHub username is: **`Prajwal-ishwar-naik`**

If your repository is currently named `Prajwal_Naik`:
1. Go to your repository on GitHub: `https://github.com/Prajwal-ishwar-naik/Prajwal_Naik`
2. Click **Settings** (tab at the top).
3. Under **Repository name**, change `Prajwal_Naik` to **`Prajwal-ishwar-naik`**.
4. Click **Rename**.
5. Once renamed, GitHub will automatically flag it with the ✨ *special repository* ✨ badge and display this README on your main profile!

---

## ⚙️ Step 2: Enable Workflow Permissions in GitHub (Crucial)

GitHub Actions need write permissions to commit your generated metrics and contribution snake.

1. In your repository on GitHub, click **Settings** (top tab).
2. In the left sidebar, click **Actions** → **General**.
3. Scroll down to the **Workflow permissions** section.
4. Select **"Read and write permissions"**.
5. Check the box **"Allow GitHub Actions to create and approve pull requests"**.
6. Click **Save**.

---

## 🐍 Step 3: Generate the Contribution Snake

1. Go to the **Actions** tab in your repository (`github.com/Prajwal-ishwar-naik/Prajwal_Naik/actions`).
2. In the left sidebar under **All workflows**, click **Generate Contribution Snake**.
3. Click the **Run workflow** dropdown on the right side.
4. Click the green **Run workflow** button.
5. Wait ~30 seconds for the green checkmark (✅). This automatically creates the `output` branch with your customized matrix green snake animations!

---

## 📊 Step 4: Generate the GitHub Metrics Dashboard

1. In the **Actions** tab, click **Generate GitHub Metrics** in the left sidebar.
2. Click the **Run workflow** dropdown on the right side.
3. Click the green **Run workflow** button.
4. Wait ~1 minute for the green checkmark (✅). This generates your live stats and commits them to `profile/metrics.svg`.
5. Both workflows are scheduled to update automatically every day!
